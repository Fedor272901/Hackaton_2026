Hackathon 2026

Git ветки:
main - стабильная версия
dev - основная ветка для разработки

команды git:

Переход в ветку
git checkout <название> - переключает в указанную ветку

Получение последних изменений
git pull - загружает последние изменения (обязательно перед началом работы)

Создание новой ветки
git checkout -b feature/name - создаёт новую ветку и сразу переключает в неё (на каждую задачу своя ветка)

Первый push ветки
git push -u origin feature/name - отправляет ветку на сервер и привязывает её

Добавление изменений
git add . - Подготавливает все изменённые файлы к коммиту (вместо точки можно перечислять конкретные файлы)

Создание коммита
git commit -m "описание изменений" - сохраняет изменения с описанием

Отправка изменений
git push - отправляет изменения на GitHub

Обновление своей ветки
git checkout dev
git pull
git checkout feature/name
git merge dev

обновляет ветку feature/name последними изменениями из dev

Слияние ветки feature/name в dev
git checkout dev
git merge feature/name
git push

добавляет работу в основную ветку разработки dev

Правила работы:
1 Не пушим напрямую в main, только через слияние веток
2 Перед работой делаем git pull
3 Коммиты с понятным описанием (можно на русском)
4 Часто коммитим (лучше много маленьких коммитов)
5 Если что-то сломалось — сразу сообщаем

Для начала работы:
клонируем репозиторий
git clone https://github.com/Fedor272901/Hackaton_2026.git
cd Hackaton_2026
Переходим в рабочую ветку
git checkout dev
git pull
Создаем свою ветку
git checkout -b feature/name
name — краткое название задачи (например: login, ui, api)
если нет файла .gitignore нужно создать
содержимое .gitignore (все фаайлы за которыми не должен следить гит и которые не должны попасть на GitHub)

.vscode/

node_modules/

**pycache**/

Создать файл .env (в нем хранятся все секреты: пароли к бд, настройки для подключения куда либо, все то что не должно быть в открытом виде в коде):
Пример файла:

PORT=5000
DATABASE_URL=your_database_url
SECRET_KEY=your_secret_key



Установка библиотек
Список библиотек хранится в файле `requirements.txt`
Установка зависимостей:
pip install -r requirements.txt
Если установили новую библиотеку:
1 Установить библиотеку:
pip install <название>
2 Обновить файл зависимостей:
pip freeze > requirements.txt
3 Закоммитить изменения и запушить:
git add requirements.txt
git commit -m "обновление библиотек"
git push

# 🚀 Hackathon 2026

## 🌿 Git ветки
- main — стабильная версия
- dev — основная ветка для разработки

---

## ⚙️ Команды Git

Переход в ветку
git checkout <название>
Переключает в указанную ветку

---

Получение последних изменений
git pull
Загружает последние изменения (обязательно перед началом работы)

---

Создание новой ветки
git checkout -b feature/name
Создаёт новую ветку и сразу переключает в неё (на каждую задачу своя ветка)

---

Первый push ветки
git push -u origin feature/name
Отправляет ветку на сервер и привязывает её

---

Добавление изменений
git add .
Подготавливает все изменённые файлы к коммиту (вместо точки можно перечислять конкретные файлы)

---

Создание коммита
git commit -m "описание изменений"
Сохраняет изменения с описанием

---

Отправка изменений
git push
Отправляет изменения на GitHub

---

Обновление своей ветки
git checkout dev
git pull
git checkout feature/name
git merge dev
Обновляет ветку feature/name последними изменениями из dev

---

Слияние ветки feature/name в dev
git checkout dev
git merge feature/name
git push
Добавляет работу в основную ветку разработки dev

---

## 📏 Правила работы

1. Не пушим напрямую в main, только через слияние веток
2. Перед работой делаем git pull
3. Коммиты с понятным описанием (можно на русском)

Примеры коммитов:
добавил <функцию> — новая функциональность
исправил <ошибку> — багфикс
переработал <часть кода> — улучшение кода без изменения логики
изменил стили / форматирование — только внешний вид / CSS
обновил README — изменения в документации
обновил зависимости — технические изменения
слил ветку <feature/name>
в процессе (не закончено) — сохранение прогресса

4. Часто коммитим (лучше много маленьких коммитов)
5. Если что-то сломалось — сразу сообщаем

## ⚙️ .gitignore

Если нет файла .gitignore — создать

Содержимое .gitignore:

# IDE
.vscode/

# Node
node_modules/

# Python
__pycache__/
*.pyc
venv/

# Env
.env

# Logs
*.log

---

## 🔐 .env файл

Создать файл .env
(в нем хранятся все секреты: пароли к БД, настройки подключения и т.д.)

Пример:

PORT=5000
DATABASE_URL=your_database_url
SECRET_KEY=your_secret_key

ВАЖНО: файл .env не добавляем в Git

## 📦 Установка библиотек

Список библиотек хранится в файле requirements.txt

Установка зависимостей:
pip install -r requirements.txt

---

Если установили новую библиотеку:

1. Установить библиотеку:
pip install <название>

2. Обновить файл зависимостей:
pip freeze > requirements.txt

3. Закоммитить изменения и запушить:
git add requirements.txt
git commit -m "обновление библиотек"
git push

# 📘 Frontend-документация: WEB-портал обращений граждан к депутатам

---

## 1. 🎯 Общее описание проекта
Web-портал для подачи, отслеживания и обработки обращений граждан к местным депутатам.  
Система поддерживает три роли: **Гражданин**, **Депутат**, **Администратор**.  
Ключевые особенности: интерактивная карта с границами округов, автоматическая привязка обращения к округу по адресу/точке, статус-трекер, фильтры в URL, админ-модерация и аналитика.

| `GET` | `/stats/*` | Аналитика |


### A. User Flow (Фронтенд-реализация)
1. **Регистрация → Авторизация → Редирект**  
   `Auth` → проверка `role` и `isApproved` → редирект в соответствующий `/dashboard`. Депутат без апрува видит заглушку.
2. **Гражданин**  
   `Dashboard` → `CreateAppeal` → валидация + отправка → toast → редирект на `AppealDetail` со статусом `new`.
3. **Депутат**  
   `Dashboard` → фильтр в URL → `AppealDetail` → смена статуса (подтверждение в модалке) → отправка ответа → обновление чата через WebSocket или polling.
4. **Администратор**  
   `Dashboard` → виджеты-ссылки → соответствующие разделы → массовые действия через чекбоксы + панель действий.
